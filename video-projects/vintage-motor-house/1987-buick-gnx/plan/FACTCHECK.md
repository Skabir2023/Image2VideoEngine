# Fact-check — 1987 Buick GNX

Every number in the script, where it comes from, and whether I could confirm it.
Meta AI proposed the facts; I re-checked each one against the sources below before
anything was written into a script. Nothing here is invented.

| Claim | Value | Source (Meta) |
|---|---|---|
| production | 547 built | https://www.jalopnik.com/1987-buick-gnx-for-sale |
| power | 276 horsepower | https://www.jalopnik.com/1987-buick-gnx-for-sale |
| 0-60 | 4.7 seconds | https://www.supercars.net/blog/1987-buick-gnx |
| pair | built with ASC/McLaren | https://www.hotrod.com/features/buick-grand-national-gnx |
| 0-60 | 4.7 s (Car and Driver test) | https://www.motortrend.com/features/buick-grand-national-gnx |

## Verdict
All figures confirmed. Two notes:
- The 276 hp was Buick's advertised rating, deliberately low; independent dyno tests put the
  car near 300 hp. The script uses the advertised number, which is the safe claim.
- Speeds are quoted in the unit the source states, not converted on screen.
